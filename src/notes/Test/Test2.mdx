# Test 2
## Test $omega^2$

### 12345

$omega=Omega T_s$ ，其中令 $omega = pi$ ，则有 $pi = (2 pi)/T_s T_s "/" 2$ ，即 $Omega=Omega_s / 2$ ，该采样率下不发生混叠的最大模拟角频率。
因此，$omega$ 是将模拟角频率的 $[0, Omega_s / 2]$ 映射到 $[0, pi]$ 上。
这个映射是**线性**的。
	$omega=Omega T_s$ ，也即 $omega dot f_s =Omega$
