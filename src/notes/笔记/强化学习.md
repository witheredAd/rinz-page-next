```typst
= 马可洛夫树
```
$\pi$ 表示选择策略，即在每一个状态 $s$ 中选择动作 $a$ 的概率，体现为一个概率函数；
$v$ 定义在状态 $s$ 下的期望收益；$q$ 定义选择动作 $a$ 的期望收益。
$v$ 的值由状态 $s$ 所能选择的所有动作 $a$ 导向的结果按选择概率对收益加权平均；
$q$ 的值由动作 $a$ 做出后依环境随机性 $P$ 导致状态转移到下一个状态 $s'$ 的概率对收益加权平均。
```typst
$
v_pi (s)&=sum_(a in A) pi(a|s) q_pi (s,a) \
q_pi (s,a)&=R^a_s + gamma sum_(s') P^a_(s s') v_pi (s')
$
```
$gamma$ 为超参数，称为折损率。$R$ 为当步即时奖励；环境随机性 $P$ 不因策略 $\pi$ 的变化而变化。
其实整体上为这个方程注入数值的只有 $R$，因此系统获得的奖励根本上是来自于 $R$. 系统的 $v$ 值可理解为状态 $s$ 下可获得的所有可能路径下奖励的期望。

```typst
= 蒙特卡洛算法 / MC
```
马克洛夫树的 $v$ 值虽然可通过动态规划方法递归地穷举决策进行计算，但这样的计算仍比较耗时。蒙特卡洛算法提出，既然 $v$ 要计算的是所有可能路径下的期望，那连续多次进行试验，将每次路径得到的奖励之和求平均，即可近似为这一期望。
蒙特卡洛算法用 $G$ 表示一次试验结束后，计算通过 $s$ 后，在路径上收获的 $R$ 的和：
```typst
$ G(s) <- R^a_s + gamma G(s') $
```
在一次试验中，按照同样的策略（也就是概率 $\pi(a|s)$）对路径进行随机选择；最终的 $v$ 值就是所有试验结果 $G$ 的平均值。
但实际上计算时，不会按 $v = sum G_i / N$ 计算，而是采用增量更新，每次获得一个新的 $G$，就把它与当前的 $\hat v$ 的差值（$Delta v$）乘一个学习率，加到 $\hat v$ 上。
```typst
$ hat(v)_"new" = hat(v)_"old" + alpha ( G - hat(v)_"old" ) $
```

蒙特卡洛是对马可洛夫的近似计算，初步减轻了计算量，同时消除了对环境因素 $P$ 的未知性。
但蒙特卡洛每一次试验都需要从头走到尾，如果最终状态很难达到，那 $G$ 就很难拿到。

```typst
= 时序差分 / TD
```
蒙特卡洛每次计算整个试验从开始到结尾获得的总收益，也即只关注 $v_\pi(s_0)$；但这样计算比较慢，时序差分（TD）提出每次试验只走 N 步，N 步之后如果没有抵达最终状态，也停止，并利用所在节点已经计算出的临时 $v$ 值更新起点的 $v$ 值。
特别地，TD(0) 表示 N=1，其更新公式为：
```typst
$ V(S_t) <- V(S_t) + alpha[R_(t+1) + gamma V(S_(t+1)) - V(S_t)]  $
```
如果抵达 $S_{t+1}$ 时该点还没有计算过 $v$ 值，那就将其定为 0.

```typst
= Q-learning & SARSA
```
上面都在计算 $v$ 值，其实 $q$ 值也可以进行类似计算。因为马可洛夫树是很同质的，尽管一层状态一层动作交替出现，但他们的结构完全相同，转移公式也几乎一致。
因此这里就出现了计算 $q$ 值的方法。如果与 MC 和 TD 思路一致，那就是直接用当前策略选择的路径进行计算，得到 SARSA：
```typst
$ Q(S,A) <- Q(S,A) + alpha[R + gamma Q(S',A') - Q(S,A)] $
```
如果给一个局部优化，让 $q$ 值从后续所有步骤中 $q$ 值最大的一个进行迭代，就得到 Q-learning：
```typst
$ Q(S,A) <- Q(S,A) + alpha[R + gamma max_a Q(S',a) - Q(S,A)] $
```
需要明确的是，Q-learning 迭代的贪婪性意味着其策略也是贪婪的，而不是随机初始化的或者说独立的。其策略就是选择最大 Q 值。
 **$epsilon$ 贪婪策略**
 
```typst
= DQN
```
Q-learning 为了得到 $max Q(S',a)$，就需要维护一个 Q-table，即输入状态 S‘ 和 a，输出当前计算的 Q 值。这就有一个局限性：状态 S 和决策 a 都只能是离散的。
DQN 在 Q-learning 的基础上，用深度神经网络代替 Q-table，由于神经网络可以拟合任意函数，因此也就可以针对任意的 a，拟合 $max Q(S',a)$ 这样的一个函数——即不再关心 $a$，只需要提供动作之后环境发生的变化 $S'$，就可以输出 Q-learning 所需的更新值。这样一来，由于不需要记录每一个 $a$ 的情况，很自然地其决策被扩展到了连续域，只要能够计算环境在一次动作之后的改变（也仍然可以引入环境随机性），之前的所有定义都依然成立。
```typst
$ Q(S,A) <- Q(S,A) + alpha[R + gamma"Q-Net"(S') - Q(S,A)] $
```
进一步地，由于 Q 网络与怎样到达当前状态的 A 无关，因此 A 仅仅是一个关于试验和试验时间的函数，
现在的问题是，怎样确定 Q 网络的损失函数。

之前的算法都在强调计算 Q/V 值，也被称作“基于值的算法”。
以下的算法会不计算 Q/V 值而直接输出策略，被称作“基于策略的算法”。

首先，用一个神经网络来表征策略 $pi_theta$，其输入为 $s_t$，输出为 $a_t$ 的分布.
策略是一个分布，因此对于神经网络来说，要输出一个分布，对于离散的决策就采用独热 softmax，对于连续的决策就采用正态分布输出一个 $mu,sigma$.
*虽然我一开始想对于连续决策让他直接输出一个值……但可能比起正态分布，误差有些大吧，因为决策对于环境应该要有一定包容性，环境的观测也可能产生误差*

这个神经网络显然可以采用任意的结构，现在的问题是损失函数。
PG 算法提出，用 MC 的 $G(s)$ 值对网络进行更新。每次更新都需要进行一次完整实验，然后获得一条路径上的 G 值。*实验是 on-policy 的，即使用神经网络输出的策略分布进行实验。*
利用这条路径上的 G 值，对网络进行更新。
设一次实验进行了 $T$ 步走到终点，则会产生 $T$ 个样本，每个样本为 $(s_t, a_t, r_t)$，同时有 $G(s_t)$. 
这时，用神经网络批量计算 $t$ 个 $pi_theta(a_t|s_t)$，得到 $t$ 个分布。其更新目标是 $G(s_t)$ 与 $a_t$ 共同作用，**当 $G(s_t)$ 为正收益时，网络应朝向 $a_t$ 优化；当 $G(s_t)$ 为负收益时，网络应远离 $a_t$ 优化。** 这可以说是强化学习和监督学习的很重要的区别，因为监督学习一直都是要朝向 label 优化的，但这里强化学习没有固定的 label，是在实验中动态生成的，因此一定有正反馈和负反馈两个方面的样本。
#强化学习 #优化

具体说来，对于决策 $a$ 是离散/连续的情况，有不同的优化函数。
当决策是离散的时候，神经网络的输出看作 softmax 朝向独热 $a_t$ 优化，优化步长为 $G_s$；
当决策是连续的时候，神经网络输出的分布计算 $a_t$ 被取出的概率优化，优化步长为 $G_s$；

这里还有一些 Trick：尽管实验中可以获得正收益和负收益，但在优化时为了避免正数陷阱，即一旦利用某个为正的 G 优化了网络，就会导致其他的策略选择的概率降低，可以在训练时对 G 做标准化 $G^* = (G - E(G))/sqrt(V(G))$，这样 G 就有正有负了。

用 TD-like 的单步估计来代替 MC 的 G 值，优化网络。
PG 上面提到的正数陷阱，在这里会更加明显。我们假设使用 Q 值估计来训练 Actor 网络，如果有多个选择 $a$ 的 Q 值都为正，那么在网络训练的早期就会使网络极大地向最早随机到的选择倾斜，从而很难向其他更高 Q 值的策略去探索。因此，至少也要使用 Q 值的均值来做训练。而对于每一个 $s$ 节点来说，Q 值的均值就是 $V(s)$，因此训练权重变为 $Q(s,a) - V(s)$；而 $Q = r + gamma V(s')$，因此训练权重就是 $r+gamma V(s')-V(s)$. 现在只要知道 V，就可以对 Actor 网络进行训练了。因此，用另一个网络 Critic 来估计 V 值。
只要最小化这个 $r+gamma V(s')-V(s)$ *的绝对值*，就可以训练出 Critic 网络了，顺带计算出来可以给 Actor 训练。这是因为，如果认为 $s'$ 就应该是 s 按最优策略走到的下一个状态，那么 $V(s)$ 就应该向 $r + gamma V(s')$ 更新！
